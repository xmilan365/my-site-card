# Jan Milan — Personal Site

A 2026 redesign of my personal site card, built as a lightweight static website for GitHub Pages.

The site is intentionally personal rather than a developer portfolio: it presents my background in data management and business, my experience at Luxair, Accenture and Lenovo, and the interests that define me outside work.

## Run locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Deploy on GitHub Pages

1. Push the contents of this folder to the repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`.
4. Save and open the generated GitHub Pages URL.
